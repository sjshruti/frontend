# Shruti Jayaswal - Portfolio Website

A modern, professional, and responsive portfolio website for Shruti Jayaswal, a passionate Frontend Developer and Computer Science graduate.

## 🌟 Features

- **Modern Design**: Clean and professional layout with pastel color scheme
- **Dark/Light Mode**: Toggle between themes with persistent preference storage
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Animations**: Smooth transitions and scroll-triggered animations
- **SEO Optimized**: Proper meta tags, structured data, and semantic HTML
- **Performance Optimized**: Fast loading with optimized images and efficient code
- **Accessibility**: WCAG compliant with proper contrast ratios and ARIA labels

## 🎨 Design Highlights

- **Color Palette**: Pastel tones including purple (#8B7CF6), pink (#F8BBD9), blue (#BFDBFE), and green (#BBF7D0)
- **Typography**: Modern sans-serif fonts (Inter) for excellent readability
- **Layout**: CSS Grid and Flexbox for responsive design
- **Animations**: CSS animations and JavaScript intersection observers

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1200px+ (Full layout)
- **Tablet**: 768px - 1199px (Adapted layout)
- **Mobile**: 320px - 767px (Stacked layout)

## 🎯 Performance Optimizations

- **Lazy Loading**: Images load only when needed
- **Critical Resource Preloading**: Important assets load first
- **Efficient Animations**: GPU-accelerated transforms
- **Optimized Images**: SVG placeholders for fast loading
- **Minimal Dependencies**: Lightweight external resources

## 🔧 Setup and Installation

1. **Clone or Download** the repository
2. **Open** `index.html` in a modern web browser
3. **Customize** content in HTML files
4. **Replace** placeholder images in the `assets/` folder
5. **Deploy** to your preferred hosting platform

## 🎨 Customization

### Colors
Update CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #8B7CF6;
    --pastel-pink: #F8BBD9;
    --pastel-blue: #BFDBFE;
    /* ... other colors */
}
```

### Content
- Update personal information in `index.html`
- Replace placeholder images in `assets/` folder
- Modify project details and links
- Update social media links and contact information

### Styling
- Adjust animations in CSS
- Modify responsive breakpoints
- Update typography choices
- Change layout preferences
